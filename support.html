Wann gibt es neue Rätsel?

Jeden Tag um Mitternacht (deutsche Zeit). Die Rätsel sind für alle Spieler gleich.

Kann ich meinen Spielstand auf ein neues Gerät mitnehmen?

Noch nicht. Dein Spielstand ist nur auf dem Gerät gespeichert, auf dem du spielst.

Wie spiele ich mit Freunden?

Tippe unten auf „Freunde“ und dann auf „Mitmachen“. Teile deinen Code mit Freunden oder gib ihren Code ein.

Wie lösche ich mein Online-Profil?

Einstellungen → „Online-Profil löschen“. Dein Name, Avatar, deine Punkte und Freunde werden sofort vom Server entfernt.
